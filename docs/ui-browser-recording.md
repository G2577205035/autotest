# 页面内 Playwright 录制

更新：2026-09-11。`2026.09.11.2` 已部署页面录制体验修订。服务器安装与回滚见 [UI 服务器部署手册](ui-server-deployment.md)。普通用户电脑无需安装 Docker 或 Playwright。

已上线体验修订 `20260911.rec4`：录制工作区接近满屏，浏览器和代码窗口左右等高；支持原始大小、适应窗口、全屏和验证操作指引。Web、UI Worker 和录制镜像已同步更新。刷新平台页面后新建录制即可使用新布局。

## 使用流程

1. 登录平台，选择项目，进入 **UI 自动化 → 录制新套件**。录制需要项目管理员或平台管理员权限。
2. 填写套件名称与测试网站地址，点击 **打开网站并录制**。页面中会显示真实的远端 Chromium 和 Playwright Inspector，直接点击、输入和跳转。
3. 添加至少一个“预期结果”验证（也叫检查点），让测试知道什么结果才算成功。最简单的方法：在左侧网页顶部录制工具栏点击 **Assert visibility**（眼睛图标，验证可见），再点击操作后应出现的标题或结果区域。要检查具体内容，选择 **Assert text / Assert value**，填写预期文字/输入值后点击 **✓** 确认。
4. 等最后一个页面操作完成，点击平台右上角 **完成并保存**。保存成功后关闭弹窗，在套件列表点击 **运行**。
5. 在运行记录点击 **详情**，查看通过/失败用例及下载截图、录像、trace、DOCX/PDF。trace 可在受信任的本机 Playwright 工具中打开；包含账号操作的产物不要上传到无关第三方。
6. 修改录制流程时，打开套件“查看 / 编辑”，选择 **重新录制为新版本**。旧运行继续引用原脚本版本。

正式平台“蓝鲨”项目已保留 **蓝鲨登录与任务列表检查** 示例：登录 → 任务管理 → 验证上传管理可见及案件名称表头，共两个检查点。它只验证这些操作及断言，不代表蓝鲨全部业务已覆盖。账号失效或页面结构改变后需重新录制。

## 为什么提示不能保存

点击、输入、跳转只记录“做什么”，检查点负责判断“结果是否正确”。例如打开任务列表后验证标题可见；翻译完成后验证结果包含预期文字。右侧脚本出现 `await expect(…)` 表示已生成验证语句。

如果保存时提示缺少检查点，无需重录：当前会话仍可继续，在录制工具栏补加上述验证，再点击“完成并保存”。新界面的“如何添加验证”提供具体步骤，缺少验证时会自动展开；仍需在会话的 15 分钟期限内完成。

## 调整录制画面

录制开始后收起环境状态卡，工作区使用窗口剩余高度。左侧测试网页视口为 1280×720，右侧代码窗口与浏览器外窗等高；新脚本会记录视口配置，回放按录制时的尺寸执行，历史脚本保持原配置。

默认“适应窗口”显示整个桌面；文字仍偏小时点击“原始大小”，按 100% 像素查看并滚动到所需区域，再点“适应窗口”恢复。点击“全屏”可放大工作区，支持退出；浏览器拒绝全屏时页面会提示使用 F11。重连会保留当前缩放选择。窄屏也可使用原始大小滚动操作。

## 关闭、重连与取消

关闭弹窗后，90 秒内重新打开“录制新套件”并选择“继续已有录制”可恢复；连接断开时点击“重连窗口”。明确点击“取消本次录制”会丢弃未保存内容。每人同时最多一个会话、平台最多两个，每个最长 15 分钟；页面 90 秒无心跳自动回收。切换项目、退出登录、撤销权限或浏览器异常退出时会结束连接并显示状态。

## 环境设置

入口为 **UI 自动化 → 录制环境设置**，录制弹窗内也可进入。窗口逐项显示 Web 连接组件、镜像、测试网络和 UI Worker 状态。服务器模式显示“服务器统一管理”，用户无需在电脑上执行安装命令。

测试浏览器处于专用 Docker Internal 网络。新网站及其调用的接口主机/端口需由管理员加入允许列表；仅填写地址不会自动放通。当前蓝鲨目标及实际页面调用的端口已准备好。配置和操作方法见服务器部署手册。

保留 PyCharm/宿主进程的本机模式：Web 与 UI Worker 共用安装目录，默认 `LIEMA_UI_RECORDER_CONNECT_MODE=loopback`；管理员保存的非敏感字段位于忽略提交的 `config/ui-runtime.local.json`，环境变量优先。两个镜像均使用已有的固定 SHA-256 ID，网络必须为专用 Internal 网络。配置变更要求 UI Worker 停止、租约释放且没有活动任务；保存配置不会自动安装组件或启动 Worker。

Compose 模式使用 `deploy/compose.ui.yml`，设置 `LIEMA_UI_RECORDER_CONNECT_MODE=network`；Web 和 UI Worker 通过 Docker DNS 连接录制网关，无需把浏览器端口发布到宿主。Web、UI Worker 需使用相同平台库、产物存储、主密钥和镜像配置。

Web 对录制连接依赖延迟导入。独立本机安装启用录制时，在实际启动 Web 的 Python 环境安装 `httpx>=0.28,<1`、`websockets>=16,<17` 后重启；系统 Python 与项目虚拟环境互不共用依赖。服务器交付镜像已经包含这些依赖。

## 执行、存储与限制

录制与回放使用官方 Playwright 1.63.0。浏览器容器非 root、只读根文件系统、无宿主目录或 Docker socket，限制 CPU、内存和进程数；Linux 大核心主机同时限制可见 CPU，避免 Chromium 线程池耗尽进程额度。临时桌面及脚本仅写容器 tmpfs，脚本通过标准输入注入，兼容 Worker 自身也运行在容器中的部署。

每个录制网关使用独立令牌，平台 HTTP/WebSocket 校验登录、创建者、项目、管理权限、来源、心跳和 Worker 所有权。浏览器页面不会获得上游令牌；已建立的 WebSocket 每 3 秒重新验证授权。

录制源码可能包含登录密码，因此整个源码加密保存在不可变套件/运行快照中，普通接口只返回占位说明。录制运行的原始 JSON、截图、录像和 trace 加密后进入 Artifact Store，下载时验证项目权限后解密；报告不回显录制源码。授权下载者仍能在原始产物中查看录入内容。`LIEMA_MASTER_KEY` 必须妥善保留，否则历史源码和产物无法解密。

远端浏览器不继承用户电脑的登录态、扩展、证书、文件或输入法。二维码/验证码、硬件密钥、桌面应用、本机文件上传、复杂中文输入法/剪贴板仍需针对目标设计。首版不提供选择器自愈或完整在线步骤编辑器。
