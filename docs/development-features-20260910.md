## 接口数据与计划

支持 JSON 数组或带表头的 CSV，最多 100 行、1 MB；同场景最多 20 个数据集、10 条定时计划。拒绝重复字段、重复列名、非有限数值和常见敏感字段，包括嵌套敏感字段。密码、Token 继续通过已有加密环境变量配置。

每行生成独立运行，保存场景和参数快照，批次并发为 1～5；历史记录不依赖后续数据集或场景版本。定时计划使用 60 秒至 30 天的固定间隔，首轮在一个间隔后运行。停机错过的周期不补跑，上轮仍有排队/运行项则跳过本周期。数据库锁防止多实例重复调度，并限制批次领取并发；创建者停用、项目停用或执行权限撤销后自动暂停计划。

最近完成记录统计包括成功、失败、中断和停止；耗时缺失时显示未采集，不按 0 计入分位数。计划使用现有接口 Worker 调度，外部 Worker 模式下仍需启动原独立 Worker。

## 独立服务器执行

`LIEMA_SERVER_EXECUTION_MODE` 默认 `embedded`，保持现有行为；所有 Web 设置为 `external` 后，由 `python -m auto_test.server_worker` 持有 SSH 会话和压测执行。Web 与 Server Worker 使用相同的平台数据库和主密钥，业务/GPU 默认同机的规则保持不变。

指令和响应都以主密钥加密后短期保存在平台数据库中，领取时清理指令正文，响应消费后删除。服务器会话不在 Web 内复制，多 Web 通过同一所有者访问。数据库租约每 2 秒续约，30 秒失联后不可再领取指令；新 Web 启动不再中断外部 Server Worker 持有的压测。停止请求直接落库，即使 Worker 暂时离线也能保留。

目前采用单个活动 Server Worker。异常退出后不会自动抢占旧所有权；**确认旧进程及其执行已停止**后才可使用 `python -m auto_test.server_worker --recover-stale`。该开关不能用于抢占仍在执行的进程。恢复后旧 SSH 会话需重新连接，未结束压测标记中断。未确认的连接响应交给原有空闲回收机制处理，避免关闭被另一请求复用的会话。

## UI 自动化首版

接受最多 20 个单层 `*.spec.js`、`*.spec.ts`、`*.test.js`、`*.test.ts`、`*.spec.cjs`、`*.test.cjs` 文件，总计 500 KB。每次保存生成不可变版本；运行保存源代码、SHA-256、环境地址、普通参数和时限快照。项目管理员导入/管理，测试执行者运行/停止，只读成员查看本项目结果。领取和运行期间复查项目及创建者权限。

首版只使用 Chromium，不提供页面内录制、自动修复选择器、第三方依赖安装或桌面控件自动化。普通参数从 `process.env.LIEMA_UI_PARAMETERS` 指向的 JSON 文件读取；不提供秘密参数注入，脚本和普通参数不得写入凭据。测试应用使用合成账号/数据，产物可能包含被测页面内容，只能由所属项目授权成员下载。

执行入口为 `python -m auto_test.ui_worker`，与 Web、普通 Worker、Server Worker 分离。缺少配置或 Worker 未在线时拒绝提交运行，但仍允许先保存套件。运行时间 10～900 秒，项目最多 20 个未结束任务；活动 UI Worker 串行执行。

| 变量 | 默认与含义 |
| --- | --- |
| `LIEMA_UI_RUNNER_IMAGE` | 空即关闭；配置为已在 Docker 本机存在的镜像 ID `sha256:...` 或固定摘要 `仓库@sha256:...` |
| `LIEMA_UI_RUNNER_NETWORK` | `none`；可由管理员改为已配置的专用 Docker Internal 测试网络，禁止 `host` / `bridge` / `default` |

可选镜像定义在 `deploy/Dockerfile.ui-runner`，Playwright 与基础镜像均固定 `1.63.0`。镜像需要提前准备，运行不拉取镜像、不安装依赖。每次创建独立容器：普通 UID 1000、只读根目录、移除所有 capabilities、禁止提升权限、1 CPU/1 GB、192 PID 上限、限定大小的 tmpfs、只挂载当前套件输入目录，不挂载平台数据目录或 Docker socket，不向容器传入宿主环境凭据。

默认断网示例使用 `page.setContent()`。需要访问测试应用时，由运维在专用测试网络准备目标和访问隔离。Docker Internal 网络限制默认外部路由，但宿主与同网络对端访问还需网络规则约束；本功能面向项目管理员审核过的测试脚本，不把普通 Docker 宣称为对恶意多租户代码的完整安全沙箱。

测试结束或停止后，先终止本次测试进程组，启动器保持容器存活，再用容器内 `tar` 导出 `/results`，最后移除容器。这里不使用 `docker cp`，因为其不支持读取 tmpfs，见 [Docker 产物复制说明](https://docs.docker.com/reference/cli/docker/container/cp/)。Worker 拒绝产物中的目录穿越、软/硬链接和特殊文件，限制单文件 30 MB、总计 60 MB。截图、录像、trace、JSON 和 DOCX/PDF 通过已登记清单下载，不直接执行导入 HTML。进程非零退出、零用例、仅跳过、预期失败或结果异常都不冒充通过。Worker 异常退出后，确认旧进程停止，再执行 `python -m auto_test.ui_worker --recover-stale` 清理其任务容器并标记中断。

官方参考：[Playwright 容器运行与版本要求](https://playwright.dev/docs/docker)、[测试配置](https://playwright.dev/docs/test-configuration)、[Docker 资源限制](https://docs.docker.com/engine/containers/resource_constraints/)。本机没有 Docker，本轮完成模拟容器流程、边界回归与页面验收，**没有宣称容器或真实目标页面实跑通过**。

## 企业登录和 Vault

默认关闭，不修改已有账号密码登录方式。平台管理员先创建用户、授予项目角色，再绑定身份服务返回的稳定 Issuer + Subject；不按邮箱自动绑定账号。移除绑定同时撤销该平台用户全部现有登录。仅支持 OIDC Authorization Code + PKCE S256、RS256 签名，校验签发方、接收方、授权方、有效期、随机数、浏览器 cookie 和一次性 state。公共登录请求最多保留 1000 个 5 分钟有效待处理状态。

| 变量 | 配置内容 |
| --- | --- |
| `LIEMA_OIDC_ENABLED` | 默认 `false`；启用时设 `true` |
| `LIEMA_OIDC_ISSUER` | 身份服务精确签发方地址，使用发现文档 |
| `LIEMA_OIDC_CLIENT_ID` | 平台的 OIDC 客户端编号 |
| `LIEMA_OIDC_CLIENT_SECRET` | 私密客户端凭据，可使用 Vault 引用；公共客户端留空 |
| `LIEMA_OIDC_REDIRECT_URI` | 平台可访问地址加 `/api/auth/oidc/callback`，须在身份服务登记为精确回调 |
| `LIEMA_ENTERPRISE_CA_BUNDLE` | 可选内部 CA 证书包路径，默认正常校验证书 |
| `LIEMA_VAULT_ADDR` | Vault HTTPS 地址 |
| `LIEMA_VAULT_TOKEN` | 由运行环境安全注入的 Vault 身份；仅授予允许路径的读取权限 |
| `LIEMA_VAULT_NAMESPACE` | 可选企业命名空间 |
| `LIEMA_VAULT_ALLOWED_PREFIXES` | 逗号分隔的挂载名/路径前缀；默认空，拒绝全部读取 |

地址必须 HTTPS，只有字面值本机回环地址允许 HTTP 进行联调。HTTP 客户端不继承系统代理，不跟随重定向，响应限制 1 MB。HTTPS OIDC 回调创建的登录 cookie 强制 Secure。

已有模型 Key、SSH 凭据和接口密钥字段可填写 `vault://挂载名/路径#字段`；平台只加密保存引用，在真正使用时读取 Vault KV v2。读取失败即报凭据不可用，不退回旧值或把引用当密码发送。主密钥本身仍使用原有运行时主密钥机制，避免启动循环依赖。令牌生命周期和轮换由外部运行身份管理，本轮不实现 Vault 自动登录/续租。

协议参考：[OIDC 身份令牌校验](https://openid.net/specs/openid-connect-core-1_0.html#IDTokenValidation)、[PKCE](https://www.rfc-editor.org/rfc/rfc7636)、[Vault KV v2](https://developer.hashicorp.com/vault/api-docs/secret/kv/kv-v2)。本轮使用模拟身份服务和真实 RSA 签名验证，未接入真实企业 IdP/Vault。

## 模型项目授权与审计

既有模型默认所有项目可用，保留兼容性。开启限制后只有所选项目可调用；限制开启且未选择项目即禁止业务使用。列表、被测模型、裁判、报告分析、报告模型和业务错误日志模型选择均检查项目授权；队列领取时再次检查模型与裁判。没有项目上下文的 CLI 不使用受限模型。

报告、连通测试和业务错误日志分析的单次模型调用记录 `model.invoke`，包括操作者、项目、模型、结果与耗时；评测引擎使用 `model.evaluation.invoke` 按**一次评测运行**记录被测/裁判配置及耗时，不冒充逐 HTTP 请求账单。审计不保存提示词、回复或 Key；日志分析从模型配置读取凭据时不会触发任务恢复。

## 性能基准与比较口径

`liema-sha256-v1` 固定 SHA-256、1 MiB 数据块、每进程预热 1 秒。设置 10～300 秒、1～64 个进程，100% CPU 负载；不能与 GPU 压测混跑。标准页面入口默认 60 秒、1 个进程；需要目标机 Python 3、setsid、base64，工具缺失时失败，不自动安装。沿用温度、内存、磁盘安全停止和用户停止；使用独立进程组，停止时只结束本任务，并清理本任务的唯一临时目录。

测量每秒完成的 MiB，100 MiB/s 对应 100 基准分；这是固定工作负载下的内部归一值，不是行业通用综合跑分。记录 Python/OpenSSL 版本、架构、实际时长、进程数及块大小。性能 DOCX/PDF 写入该结果；旧压力任务不会根据 CPU/GPU 使用率补造基准分。

选取 2～6 个终态任务，可跨机器但必须属于当前项目。不同参数默认拒绝比较，可明确选择并列展示；只有成功状态、同参数、同基准版本和 Python/OpenSSL 条件才计算首任务为 100 的相对指数。比较保存实测快照与 Word/PDF/JSON。趋势从本项目最近 100 条任务中选同目标最多 30 条已结束记录，并标注参数；缺测显示横线，失败仍保留。
