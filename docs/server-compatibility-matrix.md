## 后续处理

- 如需标准化 CPU 压测指标，由运维预装 `stress-ng`；未安装时平台使用 Python 降级引擎。
- GPU 压测默认使用已验证的容器镜像，不在宿主机安装 CUDA/nvcc，也不修改驱动。
- 启动前按显存占用和利用率二次检查；当前节点必须等维护窗口或业务 GPU 释放后，才能执行计时烧卡。
- 平台支持填写 GPU 卡号（如 `0` 或 `0,1`）；其他繁忙 GPU 不影响已释放目标卡的单卡/分批验证。
- 新节点按 compute capability 自动选镜像；Blackwell（10.0/12.0）优先 CUDA 12.8 原生镜像，缺失时仅允许 PTX 降级路径并提示专项验证。
- 多卡通信性能验证单独使用 `nccl-tests`，不与单机 GPU 压测混为一项。
