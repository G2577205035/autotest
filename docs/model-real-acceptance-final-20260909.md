# 2026-09-09 指定 Qwen 模型补充验收

> 状态：已完成本轮授权验收并发布 2026.09.09.7；自动评分与语义复核结论分别记录。

本轮按用户确认，测试平台中已保存的“蓝鲨开发环境模型 / qwen38-27b”。模型地址、调用密钥和服务器凭据均从平台配置读取，没有修改模型部署或切换外网模型。独立裁判使用已配置的 Qwen3-4B。备份、多系统/多 GPU 型号矩阵和 UI 自动化按用户要求暂缓；Redis 密码保留可选配置。

## 评分与运行修正

- 双向翻译按方向交错抽样：快速 10+10、标准 50+50、深度 100+100。明确术语表和受保护片段要求，日期、人民币金额、百分比、批次/轮次按类型校验；错日期、错币种、错数量和保护片段改写仍失败。
- 基础事实抽取识别中文与 ISO 等价日期；JSON 除字段和类型外核验具体值。报告/情报评分识别带编号、Markdown 加粗及英文括注的独立标题，以及数字与中文单位之间的排版空格。旧规则记录不回写，修正规则发布新不可变版本，再重新调用模型。
- 流式请求获取 usage，使用实际首段正文时间；缺少正常结束标记、空响应、超时和输出截断均记录异常。非流式不展示不可观测的首字延迟；吞吐注明包含排队、网络和首字等待。EvalScope 的 Token 标为后端报告值，不声称 API 精确计数。
- 独立裁判接收原始材料、参考答案和候选回答，只解析已正常结束的推理块之后的最终 JSON。非法 JSON、缺失/越界评分均保留无效状态；裁判不能覆盖确定性事实失败。格式示例约束 rubric 为对象数组。
- 深度性能按受控 RPS、并发上限、时长和请求预算执行，包含突发、持续与恢复阶段；超错误率停止递增。资源采样绑定当前选择的服务器资产，按阶段实际时间窗计算均值；缺失项不填零，常数不产生伪相关。
- DOCX/PDF 导出全部用例，跨页重复表头；Word 防止表头与首行分离和单行拆页，PDF 防止长表格整体换页造成大块空白。容量报告展示各阶段真实请求数、RPS、P95，区分请求成功和质量达标。

## 故障与资源口径

恢复探针只在临时回环网关注入 HTTP 503、客户端超时和不完整 SSE，然后转发真实模型请求。三类异常分别识别为 `http_5xx`、`timeout`、`stream_interrupted`，随后 3 次真实调用均正常恢复；首个恢复请求耗时 118.65 ms。未停止或重启共享模型服务，因此该数据不代表模型进程故障恢复时间或服务器 MTTR。

固定并发 1/2/4/8/16 共 320 次请求全部成功；最高已测并发 16，最后阶梯实际 8.7355 RPS，端到端 P95 7950 ms。测试范围内未出现明显容量拐点，不外推为服务极限。资源为所选主机及全部 GPU 的观察值，可能包含共享负载；短阶梯采样点较少，相关系数仅作描述，不能用于证明单个模型造成的资源变化。

深度测试按实际执行顺序为容量 1/2/4/8 RPS、突发、持续、恢复，共 7 阶段：请求数 60/120/237/480/32/240/60，实际 RPS 1.0826/1.8756/3.8120/7.3925/4.8901/3.8077/0.9360，P95 为 4660/4920/5660/7360/5720/5570/4480 ms。容量、持续、恢复阶段各计划 60 秒；突发最多 32 请求、并发 16；普通性能请求超时 60 秒。4 RPS 阶段在时限内完成 237 次，不把计划预算 240 写成实际请求数。

原始资源采样共 81 点（并发 13、深度 68）；深度关联 6 阶段，短突发没有满足时间窗的资源点，未填零或伪造第 7 组均值。深度吞吐与 CPU/GPU/内存相关系数为 -0.5611/0.5384/0.1340；显存占比恒定约 69.3%，相关系数不可计算。旧性能快照的阶段列表曾按负载排序，最终报告依据实际执行记录恢复顺序；原始快照不回写。旧并发执行附件的通用 dispatch_policy 文案为 bounded_rate，但各阶段 rate=-1、固定并发参数及运行方案明确，最终代码已改为准确记录 fixed_concurrency。

内部 Qwen3-4B 裁判与被测模型独立，但自动评分不替代业务专家签字。本轮未配置人工复核比例，也未虚构正式业务放行 SLA。
