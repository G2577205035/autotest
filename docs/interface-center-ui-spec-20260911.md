# 接口中心视觉规范与本地验收

更新日期：2026-09-11 · 静态资源修订：`20260911.ui2`

本次优化直接应用于原接口中心，四个页签仍在同一页面切换。没有修改后端接口、业务字段、保存/发布/执行规则、权限或弹窗流程。独立 HTML 预览使用合成数据，仅用于查看排版和双主题效果。

| 组件 | 规范 |
| --- | --- |
| 主色与状态 | 蓝色品牌令牌 `#1677ff`；沿用平台按钮对比度配色、通过绿、失败红、尚未执行灰及其他已有状态色 |
| 页面背景 | 浅色 `#f5f6f8`，深色 `#181c24`；卡片、表头、输入区域按既有语义变量分层 |
| 卡片 | 8px 圆角、1px 分割边框、弱阴影；区块间距 16px，常用内边距 20px，手机 16px |
| 字号 | 区块标题 17px/650，环境标题 15px/600，表格主名称 14px/600，表格正文 13px，辅助说明 12px |
| 页签 | 46px 高，选中加粗、蓝色 3px 下划线，底部 1px 分割线；窄屏允许页签横向滚动 |
| 输入和按钮 | 搜索、下拉与普通按钮统一 40px 高、8px 圆角；导入主按钮 44px 高、最大宽度 280px |
| 数据表格 | 表头 44px，数据行至少 64px；长内容在所属列内换行，表格区域独立滚动；悬停/键盘聚焦行高亮 |
| 行内操作 | 文字按钮；危险操作红色。接口默认显示“调试”，只读用户显示“版本”；场景默认显示“运行”，无执行权限时显示“结果”。其余原操作在悬停或键盘聚焦时显示，保持占位以避免列宽跳动 |
| 版本和状态 | 4px 微圆角版本标签及状态标签；场景结果增加状态底色、圆点与文字，保留原结果语义 |
| 分页 | 统一位于卡片底部，操作组右对齐；输入、下拉和按钮 32px 高；保留条数、翻页和指定页跳转，窄屏分行 |
| 帮助与说明 | 变量引用提示缩为顶部 10px × 12px 内边距的中性提示；场景长说明通过名称悬停提示，键盘/读屏可读取，触屏直接展示完整说明 |

## 四个页签

- **接口工作台**：240px 目录侧栏，1450px 以下为 220px；搜索框移至目录顶部，模块目录可收起，输入搜索时自动展开。目录与主列表独立成卡片，新建接口在右上角，筛选工具栏保持等高。
- **场景自动化**：场景列表与最近执行分别使用独立卡片；批量运行、新建场景右对齐；勾选、步骤、执行状态、结果、数据与计划、编辑和删除能力保留。DOCX/PDF 使用轻量链接按钮。
- **环境与变量**：1250px 以上使用 1:1 双卡片，窄屏上下排列。环境名称优先、地址说明次之；环境编辑/删除在悬停和聚焦时显示。变量表保留全部六列。
- **批量导入**：左置纵向表单，统一字段间距；帮助说明通过右上角问号打开，默认收起，展开不改变表单宽度。底部发布选项和解析按钮居中。

所有新增样式均限定在 `#view-interfaces`，使用现有浅深主题令牌。触屏设备直接显示次要操作，键盘用户可通过 Tab 聚焦原有按钮；折叠目录有 `aria-expanded`，帮助使用可键盘操作的原生 `details/summary`。
