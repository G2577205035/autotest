# 全站对齐与分页排查记录

> 日期：2026-09-09；静态资源版本：`20260909.2`。
> 范围：9 个主模块、24 个主页面/子页签，以及相关版本、成员和场景结果弹窗。

## 修复结果

- 发起测试、模型配置、接口环境与变量、接口导入、评测测试集管理使用拉伸的双栏布局；同一行面板的顶部与底部一致，内容多时按整体自然高度增长。
- 模型页安全说明改为可展开区域，模型列表每页 3 条，避免大段说明与长模型列表把左侧撑成大块空白。说明内容和安全能力保留。
- 评测详情的事件与结果区域采用同高容器；结果按 8 条从服务器分页读取，可查看第 200 条之后的明细，跨页用例序号连续。
- 修复关闭的项目成员抽屉仍参与布局、占用页面底部高度的问题。
- 修复旧样式覆盖响应式规则，导致服务器实时监控工具栏在窄屏横向溢出的问题。
- 新增 16 处分页，保留已有 6 处分页，共 22 个分页区域。上一页/下一页、总条数、当前范围、页码、空列表和末页均明确显示；轮询保留当前页，筛选或切换项目/任务按对应边界重置页码。
- 报告任务、服务器性能任务/报告和场景执行报告在数据库内按项目过滤、计数、稳定排序后分页。保留旧 `limit` 请求兼容；历史无项目数据仅对初始项目的平台管理员可见，不能先截取全库最近 500 条再过滤项目。

## 后续更新：全局主题切换

静态资源 `20260909.3` 新增全局浅色/深色选择，入口位于业务顶栏及登录/初始化页右上角。默认深色；使用当前浏览器同源 `localStorage` 保存外观偏好，CSS 加载前恢复，刷新保留并响应其他标签页变化。浏览器禁用存储时，当前页面仍可正常切换。主题切换不请求业务 API。

## 后续修复：分页下方空白与等高面板（2026-09-10，仅本地）

用户截图暴露上一轮通用滚动上限与双栏等高规则冲突。1920×911 隔离页面，42 条记录选择每页 50 条：面板高 1112px，列表被截在 547px，分页下方还剩 423px。原有静态规则存在性检查不能证明 CSS 最终计算结果正确。

现在双栏列表按面板剩余高度伸展，通过尺寸包含避免 50/100 条内容反向撑高同排表单；分页位于底部。通用滚动上限改为可按容器职责覆盖的变量，窄屏单列与独立列表保留视口上限。修复后同条件列表高 961px，分页底部距外框 23px（正常边框与内边距），左右面板底边差 0。高级参数展开时，两个面板同时增长至 1480px，列表增至 1329px，没有恢复旧上限。

实屏验证：

- 评测运行：每页 7/20/50/100 条；数据 0/1/42/137 条，100 条/页最后一页 37 条；翻页和条数变化不改变双栏高度。
- 宽度 1920/1366/1280/1181 保持双栏，1180/1040/390 恢复上下排列和视口滚动上限；浅深主题一致，分页控件无横向溢出。
- 模型配置：100 条、密钥说明展开/收起；测试集：全部内置集和手机单列；环境与变量：100 条、520px 双栏以及 1250px 单列断点；接口目录：100 条保留固定面板内滚动。
- 评测明细、用户/项目目录和成员抽屉：列表与分页相邻，底部仅正常边框/内边距；手机测试集内容区宽度与滚动宽度均为 380px，浏览器应用错误为 0。

51 项页面、分页和主题定向测试通过，321 项全量基线保留。静态修订 `20260910.4` 仅在本地；不打包或更新服务器，等待用户明确发布指令。测试使用临时隔离 SQLite、合成接口和临时本地服务，不调用真实模型或修改正式数据。
